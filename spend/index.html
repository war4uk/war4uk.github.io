Откуда берутся суммы

Ключи живут в секретах GitHub Actions, не в этом репозитории. Раз в сутки и по кнопке workflow Spend snapshot запускает scripts/collect_spend.py. Скрипт читает секреты, забирает счета и перезаписывает spend/data.json. В git попадают только суммы.

  1. Репозиторий → Settings → Secrets and variables → Actions → New repository secret.
  2. RAILWAY_TOKEN — account или workspace token Railway. Отдельного ключа только на чтение биллинга у Railway нет, этот токен может менять воркспейс.
  3. OPENAI_ADMIN_KEY — admin-ключ организации. Ключ проекта счёт не видит.
  4. CURSOR_SESSION_TOKEN — значение cookie WorkosCursorSessionToken с cursor.com. Это полный вход в аккаунт. Если есть командный admin-ключ, вместо cookie положи CURSOR_ADMIN_API_KEY: он ограничен API команды. Если заданы оба, берётся admin-ключ.
  5. RAILWAY_WORKSPACE_ID нужен только когда воркспейсов несколько.
  6. После мержа в master: Actions → Spend snapshot → Run workflow. Дальше страница обновляется сама около 09:15 по Тбилиси.

Значения секретов не нужно присылать в чат и нельзя коммитить. Если кто-то с правом править workflow захочет, он сможет изменить скрипт так, чтобы секрет утёк в лог. Для личного репозитория это ты сам.
